This folder contains parameters for BPE tokenizers trained on TinyStories and OpenWebText (see [the main README](../README.md)):
- `tinystories_train_10000`: `cs336_basics.tokenizer.BPETokenizer` trained on TinyStories train dataset with a vocab size of 10'000. 
- `owt_train_10000`: `cs336_basics.tokenizer.BPETokenizer` trained on OpenWebText train dataset with a vocab size of 32'000.
